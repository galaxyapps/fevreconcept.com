The problem

An observation about how engineering organisations are structured, not about any one of them.

Every engineering organisation of any scale employs a Head of PLM, a CAD manager, a systems owner. Those roles are real, they are competently filled, and they do not fix this — because each of them owns one tool stack inside one department.

The cost is paid at every hand-off. The same data is rebuilt rather than reused, because the receiving function cannot consume the format it arrives in. Information is re-keyed across a system boundary because no interface was ever specified. A decision waits on data that already exists somewhere else, in a form nobody downstream can open. None of it appears as a line item, because no line item exists for effort spent a second time.

The impact is silent by construction. Waste inside a department shows up against that department's budget and someone answers for it. Waste between departments belongs to no cost centre, appears in no report, and is absorbed as the normal cost of doing engineering. It is not tolerated because anyone decided to tolerate it — it is tolerated because nothing measures it.

The structural cause is ownership, not competence. A cross-department improvement carries its cost in one budget and delivers its benefit in another, so the function paying has no case to fund it and the function benefiting has no authority to demand it. The flow between departments goes unowned because no conventional role is scoped across it — every conventional role is scoped inside one.

Where engineering capacity is capped, hours recovered from re-work and hand-off friction are development capacity gained at no additional cost. It is the cheapest capacity an engineering organisation can obtain, because it already owns it.

Sectors

The same capability, stated in each sector's vocabulary.

Motorsport

Formula 1 design offices run short cycles, continuous change and a regulatory data obligation that never pauses. The work is to govern CAD and PLM so design output is conformant at release, keep mass and materials data continuous from design through manufacturing, and record product configuration per build cycle so downstream functions can establish which parts were used, where and when.

Aerospace

Aerospace pays for hand-off friction in inspection effort and re-work. Built from zero the automated design-quality system that replaced manual inspection, scaled to 350+ engineers across six international sites, with the engineering methodology, documentation and training built alongside the tool and adoption audits run to sustain methodology compliance.

Advanced manufacturing

Outside motorsport and aerospace the constraint is identical: design intent has to survive the journey to the shop floor without being rebuilt. Qualified materials consolidated into a single authoritative dataset, mass methodology aligned across manufacturing, quality and supply, configuration recorded per build cycle, and the interfaces between departments specified rather than assumed.
